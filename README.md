# Oracle-PLSQL-Self-Study
Self Study of PL SQL

Hello everyone, I created this so anyone can use and learn PL SQL.

The study Guide.

1. Install Oracle. [https://www.oracle.com/database/free/get-started/#windows] Installation Guide [https://docs.oracle.com/en/database/oracle/oracle-database/26/xeinw/installing-oracle-database-xe.html#GUID-8A8E5F6D-F00E-40BD-B74D-A41CCC502AE9]
2. Install SQLDeveloper. [https://www.oracle.com/database/sqldeveloper/technologies/download/]
3. Probably, you will need to modify the tnsnames.ora and listener.ora to get the Oracle server running on your Windows machine. I had faced challenges in setting up, references [https://docs.oracle.com/en/database/oracle/oracle-database/26/xeinw/connecting-oracle-database-xe.html] [https://docs.oracle.com/en/error-help/db/ora-12514/?r=26ai] [https://forums.oracle.com/ords/apexds/post/after-shutdown-cdb-get-ora-12514-cannot-connect-to-database-8580]
